## 🔧 Tools Summary

### merge_for_sites_enhanced.ps1
**Location:** `utils/merge_for_sites_enhanced.ps1`  
**Size:** 370 lines  
**Language:** PowerShell  

**What it does:**
1. Reads source HTML files (index.html, sensor_python.html, etc.)
2. Processes them for Google Sites compatibility
3. Removes mobile/menu elements
4. Inlines all CSS and JavaScript
5. Converts images to base64
6. Generates 4 `*_for_copy_to_sites.html` files
7. Provides interactive UI for clipboard copy

**How to run:**
```powershell
cd C:\Users\eddyk\source\repos\spike-editor\utils
.\merge_for_sites_enhanced.ps1
```

**Output files generated:**
- `index_for_copy_to_sites.html` (~50-80 KB)
- `sensor_python_for_copy_to_sites.html` (~150-200 KB) 🆕
- `training_camp_for_copy_to_sites.html` (~100-150 KB)
- `challenges_library_for_copy_to_sites.html` (~80-120 KB)

**Features:**
- ✅ Enhanced UI with colored output
- ✅ Progress tracking
- ✅ File size reporting
- ✅ Backward compatible with original script
- ✅ Can skip Sensors Python with `-SkipSensorsPython` flag
- ✅ Interactive clipboard copy-to-paste
