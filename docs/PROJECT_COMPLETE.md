## 🎯 The 4 Phases Taught

```
PHASE 1              PHASE 2              PHASE 3              PHASE 4
Move Until Touch     Move Until Near      Move Until Touch     Repeat Back & Forth
        🛑                  ☀️                   🛑                   ↔️

Robot moves          Robot moves          Robot moves          Robot bounces
forward until        forward until        forward until        forward/backward
Force Sensor         Distance Sensor      Force Sensor is      until Force
is pressed           detects object       pressed again        Sensor stops it
```
