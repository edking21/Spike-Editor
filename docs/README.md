## 🎓 The Sensors Word Blocks Project

Teaches middle school students to program LEGO SPIKE robots using:
- 🛑 Force Sensor (Touch)
- ☀️ Distance Sensor (Ultrasonic)
- 🧿 Color Sensor

### 4 Learning Phases
1. Move Until Touch
2. Move Until Near
3. Move Until Touch Again
4. Repeat Back & Forth
