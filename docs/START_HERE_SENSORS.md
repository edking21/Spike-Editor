## 🎯 The Four Phases You'll Teach

### Phase 1: Move Until Touch 🛑
Robot moves forward → Force Sensor stops it

### Phase 2: Move Until Near ☀️
Robot moves forward → Distance Sensor stops it

### Phase 3: Move Until Touch Again 🛑
Robot moves forward → Force Sensor stops it again

### Phase 4: Repeat Back & Forth ↔️
Robot bounces forward/backward → Force Sensor stops it

## 🔧 Hardware Needed Per Robot

- LEGO SPIKE Prime hub
- 2 Large Motors (Ports C & D)
- Force Sensor (Port A)
- Distance Sensor (Port B)  
- Color Sensor (Port F)
