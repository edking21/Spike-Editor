## 🎯 The 4 Phases

1. **Phase 1: Move Until Touch** 🛑
   - Robot moves forward
   - Force Sensor (Port A) stops motion

2. **Phase 2: Move Until Near** ☀️
   - Robot moves forward
   - Distance Sensor (Port B) detects objects

3. **Phase 3: Move Until Touch Again** 🛑
   - Robot moves forward
   - Force Sensor (Port A) stops motion again

4. **Phase 4: Repeat Back & Forth** ↔️
   - Robot bounces forward/backward
   - Force Sensor (Port A) stops motion

## 🔧 Hardware Required

Per robot:
- SPIKE Prime hub
- 2 Large Motors (Ports C & D)
- Force Sensor (Port A)
- Distance Sensor (Port B)
- Color Sensor (Port F)
