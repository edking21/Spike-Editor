🤖 Sensors Word Blocks

Learn to Program All Three SPIKE Sensors

Move Until Touch • Near • Touch • Repeat

📚 Learning Objectives

By the end of this lesson, students will be able to:

  • Use the Force Sensor (Touch) to detect when something is pressed and stop robot movement
  • Use the Distance Sensor (Ultrasonic) to detect when an object is near and trigger actions
  • Use the Color Sensor to detect colors (ready for future lessons)
  • Program robot sequences that use multiple sensors in combination
  • Implement repeat loops that continue until a sensor detects something
  • Understand Word Blocks concepts for robot control in LEGO Education SPIKE

🔧 Hardware Setup

  1. Force Sensor (Touch) - Connect to Port A
    This is your stop button. When pressed, it triggers the robot to stop.
  2. Distance Sensor (Ultrasonic) - Connect to Port B
    This sensor detects how far away an object is. We'll use it to detect when something is near.
  3. Color Sensor - Connect to Port F
    Ready for use in future challenges. For now, it can detect colors on the ground.
  4. Motor Pair - Connect to Ports C and D
    These drive wheels move your robot forward and backward.

📋 The Four Phases of Movement

1

Move Until Touch

🛑

Robot Action: Moves forward until the Force Sensor (Touch) is pressed.

Sensor: Force Sensor (Port A)

What Happens:

  • Robot starts moving forward at 30% speed
  • Robot waits for the touch sensor to be pressed
  • When pressed, robot stops immediately
motor_pair.move(PAIR_1, 0) await runloop.until(is_touch_1)
✓ Success: Robot moves forward and stops when you press the sensor!
2

Move Until Near

☀️

Robot Action: Moves forward until the Distance Sensor detects something close.

Sensor: Distance Sensor (Port B)

What Happens:

  • Robot starts moving forward at 30% speed
  • Robot checks distance sensor continuously
  • When object is within 200mm (7.8 inches), robot stops
motor_pair.move(PAIR_1, 0) await runloop.until(is_near)
✓ Success: Robot moves forward and stops when it detects something nearby!
3

Move Until Touch Again

🛑

Robot Action: Moves forward until the Force Sensor (Touch) is pressed a second time.

Sensor: Force Sensor (Port A)

What Happens:

  • Robot starts moving forward at 30% speed again
  • Robot waits for the touch sensor to be pressed
  • When pressed, robot stops
motor_pair.move(PAIR_1, 0) await runloop.until(is_touch_2)
✓ Success: Robot moves forward a second time and stops when touched!
4

Repeat Back & Forth

↔️

Robot Action: Moves back and forth repeatedly until the Force Sensor stops it.

Sensor: Force Sensor (Port A) - Loop control

What Happens:

  • Robot moves forward for 1 second
  • Robot moves backward for 1 second
  • This repeats until Force Sensor is pressed
while not is_touch_2(): motor_pair.move(forward) sleep(1000) motor_pair.move(backward) sleep(1000)
✓ Success: Robot bounces back and forth until you press the sensor!

🛑 Force Sensor (Touch Sensor)

Use: Detect when robot bumps into something

Function: is_pressed()

☀️ Distance Sensor

Port: B

Use: Measure how far away objects are

Function: is_near()

🧿 Color Sensor

Port: F

Use: Detect colors and line following

Function: is_blue()

👨‍🏫 Teacher Tips & Vocabulary

Wait Until: A control structure that pauses your program until a condition becomes true.

Repeat Until: A loop that keeps running code over and over until a condition becomes true.

Sensor Function: A piece of code that checks a sensor and returns True (yes) or False (no).

Velocity: How fast the robot moves (we use 30% speed = 330 units).

Async/Await: Python keywords that let your program wait for things to happen without freezing.

Extension Activities:

  • Adjust the speed: Try 10%, 50%, 100% to see how it affects movement
  • Change the distance threshold: Make the robot stop closer or farther away
  • Add sound effects: Play a beep when each phase completes
  • Add lights: Show different hub images for each phase
  • Combine sensors: Stop when EITHER touch OR distance sensor triggers
  • Create patterns: Design your own movement sequence with multiple sensors
